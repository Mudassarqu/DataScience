C2 · Technical skills and explaining the code

Arduino sketch (from your kit)

void loop() { int currentMotion = digitalRead(PIR_PIN); if (currentMotion == HIGH && lastMotionState == LOW) { motionStartTime = millis(); digitalWrite(RELAY_PIN, HIGH); // lights ON } else if (currentMotion == LOW && lastMotionState == HIGH) { digitalWrite(RELAY_PIN, LOW); // lights OFF } dwellDuration = (currentMotion == HIGH) ? millis() - motionStartTime : 0; lastMotionState = currentMotion; if (millis() - lastTelemetryTime >= TELEMETRY_INTERVAL) { ...print one line... } }
  1. Reads the PIR output on GPIO 27: HIGH means motion, LOW means none.
  2. When it changes from LOW to HIGH, the sketch remembers the start time and switches the relay (lights) ON.
  3. When it changes back to LOW, the relay switches OFF.
  4. The dwell time is how long the output has stayed HIGH.
  5. A telemetry line is printed once per interval, not on every loop.
