# Grade 9 Data Science PRO – MYP Design Portfolio Site

1. Unzip first (never open index.html from inside the zip).
2. Upload ALL folders (assets, img, lessons, stl, google-apps-script) plus the .html files to the GitHub repo root. Upload img/ and stl/ in batches of under 100 files.
3. GitHub > Settings > Pages > deploy from main / root.
4. Apps Script URL is already set in assets/config.js (quiz scores and logins go to your Google Sheet).
5. Criteria A, C and D are placeholders; Criterion B has 19 lessons.
