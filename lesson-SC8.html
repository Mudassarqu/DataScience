Lab 1 · Arduino sketch (yellow numbers)

int rawADC = analogRead(MQ135_PIN); int ppmIndex = map(rawADC, 200, 2500, 50, 1000); // L1-B ppmIndex = constrain(ppmIndex, 50, 1000); if (ppmIndex > 450) hazard = "HAZARDOUS"; else if (ppmIndex > 250) hazard = "MODERATE"; // L1-M else hazard = "CLEAN"; // AVG_N = 1 or 5 (smoothing) // L1-A
  1. Reads the MQ-135 on GPIO 36 as a raw number.
  2. map() turns the raw range into the air index. The second number is what you calibrate.
  3. The biggest threshold is tested first, so a high reading is HAZARDOUS and not MODERATE.
  4. AVG_N averages readings: steadier, but slower to warn (spec 7.1).
