    Downloads & running it for real
    

    When you have the kit, the real files below do exactly what the simulator showed.
    

    
⬇ light-detection.ino (ESP32 sketch)
⬇ 1_data_collection_ldr.py
⬇ 2_clean_analyse_ldr.py
⬇ 3_visualize_ldr.py
⬇ ldr_light_data.csv (real raw)
⬇ ldr_light_clean.csv (real cleaned)
    

    Running it on the real kit
    1. Put light-detection.ino in a folder called light-detection, open it in the Arduino IDE, choose your ESP32 board and port, and upload.
    2. Open a terminal and run pip install pyserial pandas numpy matplotlib seaborn.
    3. Close the Serial Monitor (only one program can use the port), set COM_PORT in script 1, then run python 1_data_collection_ldr.py.
    4. Run python 2_clean_analyse_ldr.py, then python 3_visualize_ldr.py to create your six figures.
    Wiring (check your kit's guide): LDR module VCC → 3V3, GND → GND, signal → GPIO 36 (VP).
