C2 · Technical skills and explaining the code

Arduino sketch (from your kit)

int currentMotion = digitalRead(PIR_PIN); // 1 if (currentMotion == HIGH && lastMotionState == LOW) { motionStartTime = millis(); // 2 digitalWrite(RELAY_PIN, HIGH); // 3 } dwellDuration = (currentMotion == HIGH) ? millis() - motionStartTime : 0; // 4 if (dwellDuration > 6000) statusStr = "CONTINUOUS_PRESENCE"; // 5 else if (dwellDuration > 2000) statusStr = "ACTIVE_OCCUPANCY"; else statusStr = "TRANSIT_PASSING";
  1. Reads the PIR on GPIO 27 as HIGH (motion) or LOW (none).
  2. Spots the moment motion starts (it was LOW, now it is HIGH) and saves the time.
  3. Switches the relay on, so the lights come on.
  4. Works out how long the current motion has lasted, in milliseconds.
  5. Turns the dwell time into a status word. The longest threshold is tested first.

Python (from Lab 2)

def clean(rows): for r in rows: if not r["Timestamp"].strip(): continue # 1 m = to_int(r["Motion_State"]) # 2 if m not in (0, 1) or d < 0: continue # 3 roll = sum(states[-10:]) # 4 ... "Duty_Cycle_Pct": round(roll/10*100, 1) # 5 return out
  1. Drops rows with no timestamp.
  2. Turns text into whole numbers (unreadable becomes 0).
  3. Drops impossible rows: a digital PIR can only be 0 or 1, and time cannot be negative.
  4. Adds the rolling 10-second activity count.
  5. Converts it to a duty cycle percentage.
