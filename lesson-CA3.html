C2 · Technical skills and explaining the code

Arduino sketch (from your kit)

int lightValue = analogRead(LDR_PIN); // 1 int lightPercent = map(lightValue, 650, 0, 0, 100); // 2 lightPercent = constrain(lightPercent, 0, 100); // 3 if (lightValue > 500) { ... "DARK" } // 4 else if (lightValue > 300) { ... "DIM" } else if (lightValue > 100) { ... "BRIGHT" } else { ... "VERY BRIGHT" } delay(500); // 5
  1. Reads the voltage on GPIO 36 as a number.
  2. Rescales 650 down to 0 onto 0 up to 100 percent, because your LDR is inverted.
  3. Stops the percent leaving 0 to 100.
  4. Chooses a word from the raw value. The biggest threshold is tested first.
  5. Waits half a second, so you get two readings each second.
